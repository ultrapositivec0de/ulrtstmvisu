# План реалізації: Модульний «Профіль» та Захищений Гаманець із секретною активацією

## 1. Огляд та цілі

Створення нового незалежного модульного повноекранного розділу **«Профіль» (`activeView === 'profile'`)**, що містить:
1. **Публічну картку автора**: аватар, Bio, репутація, підписники/підписки, живі показники Voting Power (VP%) та Resource Credits (RC%).
2. **Публічний моніторинг балансів**: відображення рідкого STEEM, SBD, Steem Power (SP), сейфа (Savings) та кнопка збору нерозданих нагород (Claim Rewards).
3. **Приховані фінансові операції (Secret Wallet Operations)**:
   - Активація блоку операцій за 4-значним секретним кодом при кліку на інтерактивний елемент біля балансів.
   - Підтримка двох шляхів підпису: **Steem Keychain** (без збереження ключів) або **Окреме сховище Active Key**, зашифроване за стандартом AES-GCM під **окремий власний PIN-код** (повністю ізольоване від сховища Posting Key).
   - Операції: Переказ (Transfer STEEM/SBD), Power Up (STEEM ➔ SP), переказ у/з Savings.
4. **Стрічка авторських дописів**: On-demand підтягування публікацій акаунта з повною підтримкою білих та чорних списків рідера для фільтрації коментарів і спаму.
5. **Спільні компоненти**: прямий доступ до загальної панелі сповіщень та Inbox.

## 2. Архітектура та нова модульна структура

Для уникнення монолітного коду функціонал розбивається на окремі слабопов'язані модулі:

```
src/
├── store/
│   └── profileStore.ts                 # Стан профілю, балансів, VP/RC та статусу активації гаманця
├── services/
│   ├── steemAccountService.ts          # Отримання даних профілю, розрахунок SP, VP%, RC% з блокчейну
│   └── walletSecurityService.ts        # Окреме AES-GCM сховище Active Key під незалежний PIN-код
├── components/
│   └── profile/
│       ├── ProfileView.tsx             # Головний повноекранний контейнер
│       ├── ProfileHeader.tsx           # Аватар, bio, шкали VP/RC, статистика
│       ├── ProfileWalletCard.tsx       # Баланси + Claim Rewards + секретна кнопка
│       ├── ProfilePostsList.tsx        # Дописи користувача з фільтрацією списків
│       ├── ProfileSecretUnlockModal.tsx# Модалка 4-значного коду активації операцій
│       ├── ProfileActiveKeyModal.tsx   # Модалка додавання Active Key під окремий PIN
│       └── ProfileTransferModal.tsx    # Модалка переказу / Power Up (Keychain або окремий Vault)
└── locales/                            # Синхронізовані i18n ключі (uk, en, es, ko)
```

## 3. Детальний покроковий план реалізації

### Етап 1: Сервіс безпеки та сховище Active Key (`walletSecurityService.ts`)
- Створення окремого сервісу безпеки для фінансових ключів:
  - Використання Web Crypto API (`AES-GCM`, `PBKDF2`, 100 000 ітерацій).
  - Зберігання під власним префіксом у `localStorage` (наприклад, `steem_wallet_active_vault_v1`).
  - **Повна ізоляція**: PIN-код та ключ гаманця ніколи не перетинаються з основним сховищем Posting Key.
  - Тимчасова сесійна пам'ять: очищення розшифрованого ключа при закритті вкладки або скиданні сесії.

### Етап 2: Сервіс профілю та розрахунків блокчейну (`steemAccountService.ts`)
- Отримання даних облікового запису (`condenser_api.get_accounts`, `rc_api.find_rc_accounts`).
- Математичні функції:
  - Розрахунок реального Steem Power: `vesting_shares` ➔ конвертація через глобальні динамічні змінні (`total_vesting_fund_steem / total_vesting_shares`).
  - Розрахунок поточного Voting Power (враховуючи час, що минув з останнього апвоуту: +20% за 24 години).
  - Розрахунок Resource Credits (RC% мана для безкоштовних транзакцій).
  - Визначення незібраних нагород (Unclaimed: `reward_steem_balance`, `reward_sbd_balance`, `reward_vesting_balance`).

### Етап 3: Стан профілю (`profileStore.ts`)
- Збереження профілю з кешуванням для запобігання надлишковим запитам до вузлів RPC.
- Керування станом гаманця:
  - `isWalletUnlocked`: boolean (чи введено 4-значний код у поточній сесії).
  - `activeAuthType`: `'KEYCHAIN'` | `'VAULT'` | `'NONE'`.
  - Завантажені дописи користувача та стан фільтрації.

### Етап 4: Компоненти профілю
1. **`ProfileHeader.tsx`**:
   - Інформативна шапка: аватар, репутація `(log10)`, нікнейм, дата створення, локація, опис.
   - Кругові/лінійні індикатори Voting Power (зелений/блакитний) та Resource Credits (фіолетовий).
   - Лічильники підписників, підписок та публікацій.
2. **`ProfileWalletCard.tsx`**:
   - Чіткі картки балансів: STEEM, SBD, Steem Power, Savings.
   - Кнопка «Зібрати нагороди» (Claim Rewards) через Posting Key або Keychain, якщо є доступні нагороди.
   - Секретний тригер активації (наприклад, замочок або клік на заголовок гаманця), що викликає `ProfileSecretUnlockModal`.
3. **Модальні вікна операцій**:
   - `ProfileSecretUnlockModal.tsx`: швидкий ввід 4-значного PIN-коду з тактильним числовим табло або звичайним полем.
   - `ProfileActiveKeyModal.tsx`: додавання власного Active Key під власний PIN-код та його тестування на блокчейні.
   - `ProfileTransferModal.tsx`: вибір активу (STEEM/SBD), адресат, сума, memo, чекбокс переказу в Savings або Power Up.
4. **`ProfilePostsList.tsx`**:
   - Дописи користувача, оформлені картками.
   - Застосування правил білого/чорного списку рідера: якщо коментатор чи згаданий автор у чорному списку — вміст згортається або пропускається.

### Етап 5: Інтеграція в додаток та глобальну навігацію
- У `Header.tsx` додати кнопку швидкого переходу до Профілю (іконка користувача біля перемикача мов/налаштувань).
- У `ReaderMobileBottomBar.tsx` та `MobileBottomBar.tsx` забезпечити перемикання на профіль.
- Можливість виклику шторки Inbox прямо з вікна Профілю.

### Етап 6: Локалізація (i18n)
- Додавання всіх ключів (`profile`, `votingPower`, `resourceCredits`, `walletBalances`, `claimRewards`, `unlockOperations`, `secretPinPrompt`, `transferFunds`, `powerUp` тощо) до:
  - `src/locales/uk.ts`
  - `src/locales/en.ts`
  - `src/locales/es.ts`
  - `src/locales/ko.ts`

### Етап 7: Верифікація та тестування
- Перевірка компіляції (`compile_applet`) та відсутність помилок типізації.
- Перевірка валідності лінтера (`lint_applet`).
- Перевірка коректності розрахунків балансів та поведінки секретного розблокування.

## 4. Безпековий дисклеймер
- Операції гаманця активуються **тільки після ручного вводу секретного коду**.
- Перевага завжди надається **Steem Keychain**, де додаток взагалі не зберігає Active Key.
- Якщо користувач обирає зберігання Active Key, воно знаходиться в **окремому зашифрованому контейнері** під окремим паролем, не пов'язаним з ключами публікації.
