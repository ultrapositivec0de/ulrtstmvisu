**Easy Steem Editor** — легкий веб-редактор для легкого й зручного створення й публікації дописів на блокчейні STEEM. Адаптований саме для відобреження контенту на [Steemit.com](https://steemit.com). Бо редакторам приділяється менше уваги під час розробки, бо програмісти й так знайють шо до чого, а простим юзерам ще треба розбираться))

Він поєднує потужність "розумного" Markdown та HTML форматування. Інтеграцію із Steem Keychain. Навіть зберігає набраний текст у реальному часі, тож випадкове закриття сторінки <sub>(за умови увмікненого java scipt)</sub>, чи навіть вимкнення електроенергії <sub>(саме це відбулось під час доопрцювання цього тексту)</sub> можна продовжити набирати текст далі. Головне, щоб воно встигло закешуватись, бо на практиці, не все встигло зберегтись швидко <sub>(потрібно доопрацювати)</sub>. 

Ще він може бути доданний для платформи Steemit.com або використовуватись автономно, просто зберігши html сторінку й бібліотеки в одну папку, і запускати html у браузері, але не буде працювати Кейчейн, проте дозволить створити допис..

В майбутньому має багато перспектив для потування на різні платформи Windows\Linux\Mac\Android\IOS. Хіба не все так просто додати до маркетів.

## 2. Наявні можливості (Що вже реалізовано у v26.5)

<table style="width:100%"><tr><td><img src="https://cdn.steemitimages.com/DQmQa9LZ1RpiQHbdUnqPdvTefFvb9aPQh7gdd5m52Cxpjnq/Hale.png" style="width:100%"></td></tr></table>


### 🎨 Зображеня        
*   **Інтелектуальна Галерея:** Розпізнавання доданих лінків у спеціальне поле. Із яких зображення формується зручну візуальну галерею в бічній панелі.        
*   **Магія в 1 клік:** **Складні** HTML-конструкції із зображеннями (обтікання текстом чи справа) створюються одним натисканням кнопки на піктограму.      
*   **Генератор Сіток (Grid Generator):** Унікальна функція, що дозволяє виділити кілька фотографій у галереї та миттєво згенерувати з них адаптивну таблицю (колаж).      
* **Розпізнавання лінків зображень:** При вставці зображень з інших сайтів у відповідне поле, редактор автоматично "очищає" URL від рекламних та аналітичних трекерів (все після `.jpg/.png`), формуючи чистий Markdown-код.

### ⚡ Розумне форматування (Smart UX)   
<table style="width:100%"><tr><td><img src="https://cdn.steemitimages.com/DQmYe3yogS4q3Py3mEynPFyp9i5cfKgtLue7yvA32j35m5a/hal_2.png" style="width:100%"></td></tr></table>  
       
*   **Auto-Word Selection:** При застосуванні форматувння більше не потрібно снайперськи виділяти слово мишкою. Достатньо поставити курсор всередині слова, і редактор автоматично застосує форматування до нього цілком. Що дуже зручно із мобільних пристроїв.        
* **Заголовок** - заголовок допису тепер сам форується із першого рядка допису, тож його не потрібно вписувати вручну.    
* **Теги**: Хмарка тегів для зручного введення, в тому числі для спільноти. (в майбутньому планується розширення до списку відомих спільнот та цілих пакетів, щоб частовикористовувані додавались в один клік).

### 📱 Мобільна адаптивність (Mobile-First Design)        
*   **Floating Tool Widget:** На смартфонах класичний тулбар займає забагато місця. Ми створили "плаваючий віджет", який з'являється над текстом лише в момент виділення слів (аналог інтерфейсу Medium).        
*   **Розділені вкладки:** На мобільних пристроях або при малій роздільній розгортці, екран зручно перемикається між "Редактором" та "Прев'ю" без втрати фокусу.   
*  **Вибір тегів за декілька кліків/тапів**.

### 💾 Збереження даних    
- **Авторезервування** допису в реальному часі.    
- **Експор** у готовий текстовий файл .md    
- **Внутрішня** база дописів (чернеток).    
- **Власна база шаблонів**, яку можна зберігати.     
- Налаштовуваний **список для згадування** потрібних акаунтів, щоб не вводити кожного разу.    
- **Недолік**, якщо це просто веб сторінка, то збереження у відбувається у кеш браузера, відповідно його очищення загрошує втраті даних. 



### 🛡️ Безпека та Автономність        
*   **Zero-Server Architecture:** Редактор не має серверної бази даних (Backend). Усі чернетки (Drafts), шаблони підписів (Templates) та списки друзів для згадок (@Mentions) зберігаються виключно в `localStorage` вашого браузера.        
*   **Native Steem Keychain:** Публікація дописів відбувається через офіційне розширення Steem Keychain, що гарантує 100% безпеку приватних ключів. Точншіе, те що ви не передаєте ніяких ключі на сайт чи веб сторінку, лише підпис через кейчейн.   
* **Може працювати без інтернету**, за умови збереження сторінки на пристрої із додаванням

## 3. Технічний Стек (Technology Stack)        
Щоб забезпечити максимальну швидкодію та незалежність проєкту, ми використовуємо сучасні, але перевірені інструменти без "важких" фреймворків:

**Використовується зараз (v26.5):**        
*   **Core:** Vanilla JavaScript (ES6+), CSS3 (Flexbox/Grid).        
*   **Markdown Parsing:** `marked.umd.js` (швидкий та безпечний рендеринг у реальному часі).        
*   **Blockchain Integration:** `steem.js` / Steem Keychain API.

### Допоміжні технології
