# План реалізації Режиму читання (Doc Reader)

## Мета
Впровадити повноцінний автономний **Режим читання** (3-й режим робочого простору) як модульну систему без монолітних файлів і без видалення існуючої панелі швидкого прев'ю.

---

## 3 Режими робочого простору
- `visual` — WYSIWYG / живий візуальний редактор.
- `markdown` — чистий код / редактор розмітки.
- `reading` — ізольований, read-only режим читання (on-demand).

---
