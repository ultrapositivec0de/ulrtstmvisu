# Покроковий протокол стандартизації UI (Step-by-Step UI Standardization)

Кожен крок є самостійним, виконується окремо та верифікується збіркою (`lint_applet` + `compile_applet`). Для переходу до наступного кроку достатньо підтвердити: «Виконуй крок X» або «Продовжуй».

## Блок А: Базова інфраструктура (Токени та Каркас)

- [x] **Крок 1: CSS-токени поверхонь та Z-індексів** [ВИКОНАНО]
  - **Файл:** `src/index.css`
  - **Дія:** Додати в `:root` та `.theme-light` змінні: `--modal-bg`, `--modal-border`, `--modal-backdrop`, `--modal-radius`, `--modal-shadow` та класи шарів `z-[500]`, `z-[1000]`.
  - **Контроль:** Збірка без помилок, нульовий вплив на існуючі компоненти.

- [x] **Крок 2: Створення еталонного компонента `BaseModal.tsx`** [ВИКОНАНО]
  - **Файл:** `src/components/modals/BaseModal.tsx`
  - **Дія:** Створити уніфіковану обгортку (єдиний backdrop, плавна анімація входження без збоїв opacity, вибір розміру `sm`/`md`/`lg`/`xl`, підтримка критичного шару `z-[1000]` для системних діалогів).
  - **Контроль:** Експорт у `src/components/modals/index.ts`, успішний `lint_applet`.
