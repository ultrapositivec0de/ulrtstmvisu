# Етап 10 (Перспективна ідея): Пакетний бекап налаштувань та фільтрів

**Статус**: Зафіксовано в базі ідей для майбутньої реалізації (без деталізації).

## Суть ідеї
- Єдиний пакетний експорт/імпорт усіх налаштувань редактора та Reader в один архів/файл (теми, інтерфейс, аудіо-пресети, білі/чорні/ігнор-списки, кеш-правила, конфіги публікації, опціонально зашифровані профілі) з вибором категорій для відновлення.
- Експорт лінків із кешованої галереї зображень (`steem_image_cache_v1` — URL, вихідні назви файлів, дати додавання/метадані) у окремий файл (`.json` / `.txt` / `.md`) з можливістю подальшого відновлення або перенесення бібліотеки зображень між пристроями.
- Сумісність зі збереженням та вибором через Android SAF (`.zip` / `.json` / `.txt` / `.md`).
