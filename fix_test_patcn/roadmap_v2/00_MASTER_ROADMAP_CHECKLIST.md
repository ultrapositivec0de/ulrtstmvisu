## 4. Загальні ворота перевірки якості (Definition of Done)

Кожен етап вважається завершеним лише після виконання всіх пунктів:
1. `npm run lint` — 0 помилок та 0 попереджень.
2. `npm run build` (`tsc && vite build`) — успішна компіляція без помилок типів.
3. Усі нові UI-рядки додано одночасно в `src/locales/uk.ts`, `en.ts`, `es.ts`, `ko.ts`.
4. Новостворені чи змінені модулі дотримуються орієнтовного порогу 350–400 рядків (окрім обґрунтованих винятків: словники, дані, цілісні парсери або рушії з єдиним інваріантом).
5. Візуальна перевірка у браузері (Desktop + Mobile viewport) на всіх темах.
