## 2. Аналіз механізму прогнозування лінків зображень та хешування

### Поточний стан (`src/utils/steemImagePrediction.ts`):
- Використовує офіційний алгоритм сервера SteemitImages (`upload.ts`):
  $$\text{imageHash} = \text{SHA-256}(\text{"ImageSigningChallenge"} + \text{fileData})$$
  $$\text{contentHash} = \text{'D'} + \text{Base58}(\text{multihash.encode}(\text{imageHash}, \text{"sha2-256"}))$$
- Повністю виключено старі застарілі та небезпечні форми без префікса `'D'` або некоректні патерни хешування.
- Додано вторинний сирий фолбек без перефікса челенджу (`SHA-256(fileData)`), а також перевірку цілості через недеструктивне зондування DOM (`new Image()`), що повністю обходить CORS-блокування заголовок відповіді CDN.
