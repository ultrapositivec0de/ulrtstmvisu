# Дорожня карта рефакторингу: Фаза 3 (Крок 3.0 і далі)

## 🎯 Основна мета
Максимально спростити та очистити файл `src/App.tsx`, винісши автономні утиліти, ізольовану логіку імпорту/експорту файлів, роботу з медіа-сервісами та допоміжні інтерфейсні блоки в окремі модулі без ускладнення взаємозв'язків.

---

## 📋 План виконання кроків Фази 3

### **Крок 3.1: Винесення автономних утиліт обробки форматування та DOM** [ЗАВЕРШЕНО]
*   **Опис:** Винесено ізольовані функції роботи з форматуванням тексту та деревом DOM.
*   **Створено файли:**
    *   `src/utils/formatUtils.ts` — функції `getAllFormatRangesInLine`, `isInsideTagInLine`, `getActiveFormatRangeInLine`, тип `FormatRange`.
    *   `src/utils/domUtils.ts` — функції `getNodePath`, `getNodeByPath`.
*   **Результат:** Чистий імпорт утиліт у `App.tsx` та зв'язаних хуках, успішно видалено зайві рядки та пройдено перевірку компілятора.

---

### **Крок 3.2: Винесення парсера Markdown та конфігурації DOMPurify** [ЗАВЕРШЕНО]
*   **Опис:** Ізольовано логіку парсингу Markdown, захисту від XSS (`DOMPurify`) та спец-обробки таблиць/списків.
*   **Створено файл:**
    *   `src/utils/markdownParser.ts` — `DOM_PURIFY_CONFIG`, `getMarked()`.
*   **Результат:** Усі правила парсингу та очищення HTML знаходяться в окремому модулі, успішно підключено у `App.tsx` та хуках, пройдено перевірку компілятора.

---

### **Крок 3.3: Екстракція утиліти універсального збереження файлів `saveFileNatively`** [ЗАВЕРШЕНО]
*   **Опис:** Винесено велику функцію `saveFileNatively`, яка підтримує кросплатформене збереження (Tauri, Neutralino, Android Bridge, Web File System Access API, Web Share, Blob fallback).
*   **Створено файл:**
    *   `src/utils/fileSaver.ts` — `saveFileNatively`.
*   **Результат:** Усі нативні збереження файлів ізольовані у зручному файлі-утиліті, успішно підключено у `App.tsx`, пройдено перевірку компілятора та збірки.

---

### **Крок 3.4: Створення хука імпорту та експорту даних `useImportExport`** [ЗАВЕРШЕНО]
*   **Опис:** Винесено логіку завантаження/вивантаження чернеток, шаблонів, резервних копій (ZIP/JSON) та файлів Markdown.
*   **Створено файл:**
    *   `src/hooks/useImportExport.ts` — функції експорту в Markdown/JSON/ZIP та обробники імпорту з перевіркою формату.
*   **Результат:** Повна ізоляція файлових операцій користувача, успішно інтегровано в `App.tsx`, пройдено компіляцію.

---

### **Крок 3.5: Створення хука пошуку та інтеграції зображень `useImageSearch`** [ЗАВЕРШЕНО]
*   **Опис:** Винесено стан та обробники роботи з Pexels, Pixabay та Unsplash (пошук, кешування результатів, запити до API з обробкою помилок та проксі).
*   **Створено файл:**
    *   `src/hooks/useImageSearch.ts` — керування режимами галереї медіа-стоків та пошуковими запитами.
*   **Результат:** Повне відокремлення зовнішніх медіа-сервісів від головного редактора, успішно інтегровано в `useSteemGallery`, пройдено перевірку компілятора та збірки.

---

### **Крок 3.6: Оптимізація та підключення `AppModals`** [ЗАВЕРШАЛЬНИЙ ЕТАП]
*   **Опис:** Перевірка та остаточний зв'язок модальних вікон через компонент `AppModals`, що дозволить звести JSX у `App.tsx` до декількох лаконічних блоків.
