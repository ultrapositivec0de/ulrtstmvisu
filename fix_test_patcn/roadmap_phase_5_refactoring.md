# Роадмап Рефакторингу (Фаза 5) — Декомпозиція та оптимізація App.tsx

Цей документ містить покроковий план декомпозиції кореневого файлу `/src/App.tsx` (який наразі має ~1635 рядків коду) на окремі логічні модулі та кастомні React-хуки. Мета рефакторингу — зменшити розмір `App.tsx` щонайменше на 25-30% (~400+ рядків), ізолювати бізнес-логіку, покращити Hot Module Replacement (HMR) у Vite та підвищити стабільність коду.

---

## 📅 Покроковий План Рефакторингу

### Крок 1. Автозбереження та відновлення тексту (Autosave Engine)
* **Поточне розташування:** `App.tsx` (Рядки `874–940` та ініціалізація відновлення `943–954`).
* **Опис завдання:** Створення кастомного хука для повної ізоляції збереження тексту в `localStorage`/`sessionStorage` та автоматичного відновлення при перезавантаженні вкладки.
* **Створення нового файлу:** `/src/hooks/useEditorAutosave.ts`
* **Що переноситься:**
  - `useEffect` з дебаунс-збереженням контенту.
  - Рефи та допоміжна функція `saveLargeStorage`.
  - Ефекти слухання системних подій браузера: `beforeunload`, `pagehide`, `visibilitychange` (для примусового збереження перед закриттям вкладки).
  - Логіка завантаження чернетки на старті застосунку.
* **Результат для `App.tsx`:** Скорочення на **~90 рядків**.

---

### Крок 2. Синхронізація Живого Прев'ю (Live Preview Rendering & Morphing)
* **Поточне розташування:** `App.tsx` (Рядки `964–1039`).
* **Опис завдання:** Очищення кореневого компонента від логіки низькорівневої роботи з HTML-парсингом, санітизацією (`DOMPurify`) та інтеграцією з алгоритмом `Idiomorph` для морфінгу дерева DOM.
* **Створення нового файлу:** `/src/hooks/useLivePreviewSync.ts` (або перенесення безпосередньо у `/src/components/editor/PreviewPane.tsx`).
* **Що переноситься:**
  - Налаштування `marked` (рендер посилань, параграфів тощо).
  - Ефект `useEffect`, який слухає зміни в `useEditorStore` і компілює Markdown у HTML.
  - Логіка очищення через `DOMPurify` та заміни зображень на кастомні посилання.
  - Виклик нативного морфінгу `Idiomorph.defaults.morph`.
* **Результат для `App.tsx`:** Скорочення на **~80 рядків**, повна ізоляція рендерингу прев'ю.

---

### Крок 3. Відстеження курсору, таблиць та виділення (Selection Tracker)
* **Поточне розташування:** `App.tsx` (Рядки `813–872`).
* **Опис завдання:** Ізоляція слухача подій виділення тексту (`selectionchange`), який відповідає за відображення контекстних інструментів для роботи з HTML-таблицями.
* **Створення нового файлу:** `/src/hooks/useSelectionTracker.ts`
* **Що переноситься:**
  - Подія `document.addEventListener('selectionchange', ...)` та очищення слухача.
  - Функція обходу DOM-дерева вгору для пошуку елементів `table`, `tr`, `td` від каретки курсора.
  - Керування стейтом активної таблиці для виклику контекстної панелі.
* **Результат для `App.tsx`:** Звільнення від низькорівневої математики виділення вузлів. Скорочення на **~60 рядків**.

---

### Крок 4. Керування конфігурацією плаваючих інструментів (Floating Toolbar Config)
* **Поточне розташування:** `App.tsx` (Рядки `780–810` та `1074–1091`).
* **Опис завдання:** Винесення логіки налаштування інструментів, додавання/видалення кнопок та зміни їх черговості у кастомний хук.
* **Створення нового файлу:** `/src/hooks/useToolbarConfig.ts` (або інтеграція в наявний `useEditorFormat.ts`).
* **Що переноситься:**
  - Функція `toggleTool` (показувати/приховувати кнопку інструмента).
  - Функція `moveTool` (переміщення вліво/вправо у черзі).
  - Логіка автовизначення напрямку випливання меню (`up`/`down`) залежно від висоти.
* **Результат для `App.tsx`:** Полегшення стейт-менеджменту панелі. Скорочення на **~50 рядків**.

---

### Крок 5. Допоміжні функції та константи (State Helpers & Dictionary)
* **Поточне розташування:** `App.tsx` (Рядки `1041–1072`).
* **Опис завдання:** Винесення статичних констант, тегів та згадок користувачів у відповідні тематичні файли.
* **Що переноситься:**
  - Функції `toggleTag` та `addMention` (можуть бути інтегровані в кастомний хук `usePostSettings.ts`).
  - Статичні константи ключів `localStorage` (виносяться у окремий спільний файл констант `/src/utils/constants.ts`).
* **Результат для `App.tsx`:** Зменшення на **~40 рядків**.
