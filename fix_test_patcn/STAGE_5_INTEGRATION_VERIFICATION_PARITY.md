# Етап 5: Комплексна Верифікація, Крос-Платформний Паритет та Локалізація

## 1. Мета та Контекст
- Забезпечити повну стабільність, відсутність функціональних регресій та перевірку паритету після завершення всіх етапів рефакторингу.
- Перевірити роботу в усіх 4 середовищах:
  1. Web (Vite SPA у сучасному браузері).
  2. Android контейнер / PWA (включаючи тач-взаємодію та клавіатуру).
  3. Tauri (Desktop з нативним WebKit).
  4. Neutralino (Desktop WebKit рушій).
- **Складність:** Середня (Medium — комплексне тестування та валідація правил).
- **Оцінка холостого ходу (контекст):** ~1,500 токенів.

---

## 2. Мікрокроки реалізації

### Мікрокрок 5.1: Аудит локалізації (i18n)
- Перевірити відповідність стандарту з `RULE[AGENTS_md]`:
  - Жодних захардкоджених рядків у нових компонентах (`PostRenderer`, `AppModalsHost`, `EditorCanvas` тощо).
  - Усі нові ключі синхронізовані в 4 словниках: `src/locales/uk.ts`, `src/locales/en.ts`, `src/locales/es.ts`, `src/locales/ko.ts`.
  - Запуск скрипта валідації локалей `bun run fix_test_patcn/audit_localization.ts`.

### Мікрокрок 5.2: Перевірка дизайн-токенів та стабільності в'юпорту
- Перевірити:
  - Усі модальні вікна базуються на `BaseModal` та використовують `--modal-bg`, `--modal-border`, `--modal-radius`.
  - Відсутність вертикального смикання шапки `#main-header` при відкритті модалок або спливаючих панелей.
  - Наявність `overscroll-behavior: contain` на контейнерах.

### Мікрокрок 5.3: Перевірка взаємодії клавіш у списках, таблицях та цитатах
- Перевірка поведінки списків (Enter, Backspace, перехід від параграфа до списку), що обговорювалась у попередніх запитах.
- Робота віджетів на вузьких екранах мобільних пристроїв.

### Мікрокрок 5.4: Фінальна компіляція та збірка
- Виконати `compile_applet` — очікується повний успіх збірки (`npm run build`).
- Виконати `lint_applet` — 0 помилок синтаксису чи типізації.
- Замір продуктивності: зменшення загального часу ререндерингу в редакторі.
