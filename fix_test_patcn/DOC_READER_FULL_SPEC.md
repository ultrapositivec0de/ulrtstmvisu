# Повна специфікація та архітектура Режиму читання (Document Reader)

## 1. Контекст та аналіз поточної системи

### 1.1. Проблематика поточного прев'ю (`PreviewPane.tsx`)
1. **Тіснота та нераціональне використання екрана:** Стандартне роздільне прев'ю (Split View) ділить екран навпіл, звужуючи робочу область і перевантажуючи інтерфейс кнопками форматування.
2. **Незручність для тривалого читання:** У редакторі курсор залишається активним, що несе ризик випадкового введення символів чи видалення фрагментів тексту.
3. **Обмеженість джерел:** Старе прев'ю прив'язане суто до активного буфера поточного редактора й не дозволяє швидко читати збережені чернетки або локальні файли з диска без перезапису відкритого тексту.

### 1.2. Розмежування: Blockchain Reader vs. Document Reader
* **Blockchain Reader (`/src/components/Reader.tsx`):** Глобальний клієнт для взаємодії з блокчейном Steem (пошук постів через Steem API, читання чужих блогів, перегляд коментарів, голосування/апвоути).
* **Document Reader (`/src/components/docReader/`):** Локальний безвідволікальний рідер для власних текстів (поточний пост, збережені чернетки, локальні файли Markdown/HTML з диска) зі зручною навігацією, змістом (TOC), налаштуванням шрифтів і тем для комфорту очей.

### 1.3. Принцип збереження Split Preview
Панель швидкого прев'ю (`PreviewPane.tsx`) **не видаляється**, щоб зберегти звичний сценарій швидкої перевірки коду під час набору. Новий Режим читання стає самостійним третім робочим простором.

## 2. Модульна архітектура (`/src/components/docReader/`)

Для запобігання монолітності система розбивається на окремі незалежні компоненти:

```
src/components/docReader/
├── DocReaderContainer.tsx        # Головний контролер режиму (on-demand рендеринг)
├── DocReaderToolbar.tsx          # Верхня плаваюча панель керування (навігація, повернення)
├── DocReaderContent.tsx          # Ізольований рендерер тексту (read-only, typography presets)
├── DocReaderTOC.tsx              # Інтерактивна бічна шторка змісту (Outliner / H1-H6)
├── DocReaderSourceDrawer.tsx     # Панель вибору джерел (Поточний текст / Чернетки / Файл)
├── DocReaderSettingsMenu.tsx     # Меню налаштування очей (кольорові теми, ширина, шрифт)
├── useDocReader.ts               # Хук бізнес-логіки (TOC-парсинг, прогрес, час читання)
└── index.ts                      # Точка експорту
```

## 3. Детальний опис компонентів та їхніх функцій

### 3.1. `DocReaderContainer.tsx`
* **On-Demand Lifecycle:** Монтується виключно тоді, коли `editorMode === 'reading'`. В інших режимах не споживає пам'ять та ресурси процесора.
* **Безпека:** Вимикає гарячі клавіші редактора, запобігає появі каретки та випадковим модифікаціям тексту.

### 3.2. `DocReaderSourceDrawer.tsx` (Джерела читання)
* **Поточний документ:** Миттєвий перегляд актуального стану редактора.
* **Локальні чернетки:** Список усіх збережених чернеток із можливістю читання будь-якої без затирання тексту в редакторі.
* **Файли з диска/папки:** Кнопка відкриття локального файлу (`.md`, `.txt`, `.html`) для прямого читання.
* **Дія «✏️ Редагувати цей текст»:** Завантажує обраний матеріал у робочий буфер і перемикає у візуальний чи кодовий редактор.

### 3.3. `DocReaderTOC.tsx` (Інтерактивний зміст)
* Автоматичне вилучення заголовків `H1..H6` з відрендереного Markdown/HTML.
* Деревоподібний зміст у компактній шторці.
* Плавний скрол до розділу та підсвічування активного заголовка під час прокрутки.

### 3.4. `DocReaderSettingsMenu.tsx` (Комфорт для очей)
* **Колірні профілі:**
  - `paper`: Світлий м'який папір.
  - `sepia`: Тепла сепія (захист очей від синього світла).
  - `dark`: Графітовий темний режим.
  - `oled`: Глибокий чорний (OLED True Black).
* **Ширина шпальти тексту:**
  - `narrow` (65ch — стандарт книжкової верстки),
  - `medium` (85ch),
  - `full` (100% ширини контейнера).
* **Типографіка:** Розмір тексту (16px..24px), міжрядковий інтервал (1.5..2.0).

### 3.5. `useDocReader.ts` (Логіка стану)
* Розрахунок часу читання на базі лічильника слів (середня швидкість 180-220 слів/хв).
* Відстеження відсотка скролу документа (тонкий верхній прогрес-бар).
* Збереження останньої прочитаної позиції для чернеток.

## 4. Інтеграція в редактор

1. **Модель трьох режимів (`useEditorModeManager.ts`):**
   - `editorMode: 'visual' | 'markdown' | 'reading'`
2. **Сегментований перемикач у Header / Mobile Bar:**
   - `[ ✍️ Візуальний | 💻 Код | 📖 Читання ]`
3. **Синхронізація при поверненні:** При натисканні кнопки «Редагувати» або виборі іншого режиму стан тексту та позиція читання коректно передаються в редактор.
